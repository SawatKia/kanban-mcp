# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added

- Repository security and contribution documentation.
- GitHub Actions validation and CodeQL workflow.
- GitHub issue forms and pull request template.

### Changed

- Hardened Docker Compose database/network defaults.
- Standardized the project on npm lockfiles and install commands.
- Expanded agent-oriented Kanban operations and query capabilities.

### Security

- Removed tracked runtime environment credentials from the public repository history.
- Added .env.example with placeholders only.
- Enabled repository-side secret scanning and push protection.

## [0.0.6]

Initial public community-maintained release based on the upstream bradrisse/kanban-mcp project.
